# 果酱罗盘 · 隐私政策

**生效日期：2026 年 10 月**

## 一、总则

本 App 为**非官方逆向研究版**，由个人研究者出于技术学习目的构建。本政策说明本 App 会接触哪些设备能力、这些数据流向何处，以及您可以如何控制。

核心结论：**本 App 不采集、不上传、不出售您的个人信息。** 所有涉及设备权限的功能均在本地完成计算。

## 二、会申请的设备权限及用途

| 权限 | 用途 | 数据是否离开设备 |
|---|---|---|
| 相机 | 实景罗盘叠加显示 | 否，仅本地实时渲染 |
| 位置（粗略/精确） | 真北校正、磁偏角计算 | 否，仅本地计算 |
| 传感器（磁力计/加速度计/陀螺仪） | 罗盘指向、水平仪 | 否 |
| 存储/文件 | 导出罗盘截图 | 否，仅写入本机相册 |
| 网络 | 检查更新、加载在线内容 | 仅访问本仓库文件 |
| 通知 | 本地提醒 | 否 |

以上权限均可在系统设置中随时关闭；关闭后仅影响对应功能，不影响基本使用。

## 三、数据的收集与使用

1. 本 App **不收集**任何个人身份信息（姓名、手机号、邮箱、通讯录、IMEI、MAC 等）。
2. 本 App **不接入**任何第三方统计、广告或崩溃上报 SDK 的采集通道；原应用中集成的第三方 SDK 代码虽仍存在于安装包内，但其网络请求指向的服务在研究中不可用，不会产生有效数据上报。
3. 本 App **不读取**您设备上的其他应用数据。

## 四、本地存储的数据

以下数据仅保存在您设备本机的应用私有目录，卸载 App 时随之删除：

- 黄历数据库（由加密资源 `data_hlwfestival.dt` 解密释放，约 2 MB）
- 排盘记录、收藏、设置项
- 应用运行缓存与日志

## 五、网络请求

本 App 出网请求仅包括：

1. **检查更新**：拉取本仓库的 `update.json` 与 APK（`raw.githubusercontent.com`）。
2. **打开协议页**：跳转本仓库的 GitHub 渲染页面。

除此之外，原应用中指向原厂商服务端的接口地址虽然在安装包内保留，但在本研究中**不会发起有效业务请求**，也不涉及您的个人信息。

## 六、未成年人保护

本 App 仅供技术研究，不面向未成年人。若您是未成年人，请在监护人陪同下使用。

## 七、您的权利

由于本 App 不采集任何个人信息，不存在需要「查询、更正、删除」的个人数据。若要清除全部本地数据，请：设置 → 应用 → 果酱罗盘 → 存储 → 清除数据；或直接卸载应用。

## 八、政策更新

本政策可能随研究进展调整，更新后的内容以本页面为准。

## 九、联系

如对本政策有疑问，或原权利人认为存在侵权，请通过本仓库 Issue 联系，我们将及时处理。
