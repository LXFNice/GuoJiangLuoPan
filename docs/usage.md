# 果酱罗盘 · 使用说明

> 本页由研究版 App 通过「设置 → 关于 → 使用说明」打开。本 App 为**非官方逆向研究版**，与原开发者无关。

## 一、安装

1. 下载本仓库根目录的 `GuoJiangLuoPan.apk`。
2. 在手机上允许「安装未知来源应用」。
3. 安装后桌面名称为 **果酱罗盘**，包名为 `com.gj.luopan.compass`，可与原版 App 共存。
4. 系统要求：Android 7.0（API 24）及以上，arm64-v8a。

> 首次启动如提示网络或推送权限被拒绝，属正常现象，可忽略。

## 二、主要功能

| 模块 | 说明 |
|---|---|
| 智能罗盘 / 实景罗盘 | 调用设备磁力计与相机，实时显示方位角、二十四山、穿山七十二龙等读数 |
| 鲁班尺 / 水平仪 | 本地尺规与倾角测量 |
| 黄历择日 | 本地黄历数据库（`hlwfestival`），宜忌、神煞、节气、节日离线可查 |
| 八字排盘 / 紫微斗数 | 本地排盘与星曜推算 |
| 每日工具 | 每日一签、养生时辰、穿衣指南、五行手串、周公解梦、生肖运势等 |
| 祈福工具 | 祈福明灯、大德符运、藏宝阁等（部分需联网） |

## 三、与官方版的差异

1. **会员校验已移除**：`UserVipManager` 相关判定在本地恒为「已开通」，原会员墙不再拦截。
2. **品牌信息已替换**：应用名、图标文案、包名与本说明页均已改为研究版标识。
3. **协议页面改指向**：服务协议与隐私政策指向本仓库文档，不再请求原厂商服务器。

## 四、已知限制（预期行为，非 Bug）

- **联网功能不可用**：排盘上传、订单、支付、社区、账号登录等依赖原厂商服务端的接口，因研究环境无法访问而失效。
- **推送与分享失效**：厂商推送通道、微信支付回调、第三方分享因包名与签名变更无法回调。
- **首次进入黄历页需要 1～2 秒**：App 需在首次启动时从加密资源 `data_hlwfestival.dt` 解密并释放黄历数据库（约 2 MB）。若中途强杀进程，可能残留空库文件，清空应用数据后重启即可重建。

## 五、常见问题

**Q：安装时提示「与已有应用签名冲突」？**
A：研究版使用独立包名 `com.gj.luopan.compass`，理论上不会与官方版冲突。若曾安装过本仓库的历史版本，请先卸载再安装。

**Q：打开后一直在启动页？**
A：多为首次解密数据库未完成或被杀进程。请：设置 → 应用 → 果酱罗盘 → 存储 → **清除数据**，然后重新打开并保持前台 3 秒。

**Q：罗盘指向不准？**
A：请先做「8 字形」磁力计校准，并远离金属、磁铁与电子设备。

## 六、卸载

设置 → 应用 → 果酱罗盘 → 卸载。卸载后本地数据（含已释放的黄历库）一并删除。
